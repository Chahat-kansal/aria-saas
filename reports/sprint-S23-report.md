## Gap 1 — BAS auto-population

**What was built:**
- New API route `/api/compliance/bas` reads the current quarter's `bas_draft` (already auto-generated by the `bas-agent` cron near quarter-end)
- Also reads `business_expenses` and computes GST credits (1B) = `sum(amount) * 0.1`
- Returns merged BAS fields: G1, 1A, 1B, net GST, W1, W2, super, total payable
- New **BAS tab** on `/dashboard/compliance` shows these fields in a formatted table
- **"Copy for ATO portal"** button formats all fields as copy-paste text

**Pre-fill behaviour:**
- If a `bas_draft` exists for current quarter → all fields pre-filled from draft
- If no draft yet → shows message "generated automatically near quarter-end"
- `field_1b_gst_credits` from draft takes precedence; falls back to `business_expenses × 0.1` if not set

**ATO export format copied:**
```
BAS Q4 FY2026 (1 Apr 2026 – 30 Jun 2026)
Due: 28 Jul 2026

G1  Total sales:              $XXXXX.XX
1A  GST on sales:             $XXXXX.XX
1B  GST credits:              $XXXXX.XX
    Net GST payable:          $XXXXX.XX

W1  Total wages:              $XXXXX.XX
W2  PAYG withheld:            $XXXXX.XX
S   Super guarantee:          $XXXXX.XX

TOTAL PAYABLE TO ATO:         $XXXXX.XX

Generated by Aria OS — verify with your accountant before lodging.
```

## Gap 2 — AU penalty calendar

**What was built:**
- Static AU tax dates generated in the API and returned to the compliance page
- Dates covered: BAS/PAYG quarterly (28 Oct, 28 Feb, 28 Apr, 28 Jul), Super quarterly (28 Oct, 28 Jan, 28 Apr, 28 Jul)
- Calendar card appears on ALL tabs of the compliance page (not just BAS tab)
- Each card shows: label, date, days-until countdown
- Colour coding: green (>14d), amber (≤14d), red (overdue)

## Aria Intelligence triggers

1. **14-day BAS reminder** — `upsertAriaAction` fired when draft exists, status ≠ 'lodged', and BAS due within 14 days
   - category: 'compliance', priority: 'high'
   - title: "BAS Q4 FY2026 due in 14 days"
   - Deduped via existing upsertAriaAction logic (refreshes if already pending)

2. **GST spike detection** — `upsertAriaAction` fired when current quarter GST > prior quarter by >20%
   - category: 'compliance', priority: 'high'
   - title: "GST spike detected — Q4 FY2026"
   - Compares `field_1a_gst_on_sales` current vs prior quarter

3. **Note:** The `bas-monitor` cron (already running daily at 22:00) also fires `aria_autopilot_actions` for 14-day reminders. The new compliance page fires `aria_actions` (different table) on page load. Both work in parallel.
